# Skill Havuzu

Claude Code'da farkı yaratan model değil, kurduğun skill seti. Yanlış skill context'i şişirir, usage'ı boşa yakar. Doğru skill aynı işi yarı tokenla bitirir.

X'te dolaşan 22'lik Claude Code skill listesi tek tek doğrulandı. 5'i elendi, kalan 17'si altı gruba ayrıldı.

[**Sayfayı aç →**](index.html)

## Neden

Orijinal postta linkler `lnkd.in` kısaltmasıydı — hiçbiri doğrudan repo'ya gitmiyordu. 22 maddenin her birinin gerçek repo'su bulundu, sahibi ve içeriği kontrol edildi.

## Eleme kriteri

| Kriter | Soru |
|---|---|
| Skill mi | Framework ya da kütüphane değil, gerçekten bir agent skill'i mi |
| Kanonik repo | Dağınık forklar değil, tek bir kaynak repo var mı |
| Örtüşme | Listede aynı işi yapan başka bir skill zaten var mı |

**Elenenler:** `remotion` (skill değil, React video framework'ü) · `codex` (kanonik repo yok) · `marketingskills` (doğrulanabilir kaynak repo yok) · `i-have-adhd` (caveman ve ponytail ile örtüşüyor) · `social-media-skills` (postu yazanın kendi reklamı)
