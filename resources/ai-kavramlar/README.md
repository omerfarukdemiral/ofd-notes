# ai'ın hayatımıza soktuğu terimler

token'dan drift'e, ai ile çalışırken her gün duyulan 46 kavram. 6 animasyonlu şema, her kavram bir adım.

[**Sayfayı aç →**](https://omerfarukdemiral.github.io/ofd-notes/resources/ai-kavramlar/) · [video (mp4, 4:15)](ai-kavramlar.mp4)

## Şemalar

| # | Şema | Kavramlar |
|---|---|---|
| 01 | masa | token, context window, system prompt, few-shot, multimodal, prompt caching, compaction, memory, context engineering |
| 02 | model | inference, latency, reasoning / thinking, sampling / temperature, hallucination, fine-tuning, distillation |
| 03 | dış bilgi | chunking, embedding, vector database, grounding / rag, reranking |
| 04 | eller | tool calling, structured output, mcp, skill |
| 05 | döngü | workflow, loop, exit criteria, agent, planning, state, harness, human-in-the-loop, sub-agent, graph, orchestration / multi-agent, cost per task |
| 06 | ölçüm | trace, observability, golden dataset, eval, llm-as-a-judge, guardrail, prompt injection, red teaming, drift |

## Kullanım

- `→` / `←` adım, `boşluk` otomatik oynat, `r` baştan
- mobilde dokun ya da kaydır; yatay ekranda daha rahat okunur
